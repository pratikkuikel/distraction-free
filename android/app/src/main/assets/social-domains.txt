# Hand-maintained social-media feed/content domains — scheduled block
# (20:00-09:00 daily forced, toggleable 09:00-20:00), NOT from HaGeZi.
# Communication apps (WhatsApp, Messenger, Telegram, Botim) are deliberately
# never listed here — see docs/mvp-plan.md for the reasoning.
#
# Format: same as the always-on lists — one domain per line, blocking it
# and all its subdomains. "*." prefix optional, stripped either way.
#
# fbcdn.net deliberately excluded despite being Instagram/Facebook
# infrastructure: it's Meta's *shared* CDN, also used by WhatsApp for
# media/link previews. On macOS (domain-only blocking, no per-app
# exemption) this collaterally delayed/broke WhatsApp Desktop. Blocking
# instagram.com/facebook.com's own domains already covers the intended
# target without this collateral cost.
#
# googlevideo.com is the actual video/audio streaming CDN for YouTube
# (watch pages/API/thumbnails use youtube.com/ytimg.com, but the video
# bytes themselves come from *.googlevideo.com) — without it, YouTube
# videos and Shorts kept playing even with the app/thumbnails blocked.
# ggpht.com serves channel avatars and some thumbnails.
